# The $2B AI Startup Backed By Nvidia & Adobe | Synthesia

主持人 Guy 認識 Victor Riparbelli 大約五年。Victor 是 Synthesia 的 CEO 與共同創辦人，字幕把公司名聽成 Cynthsia、Cynthia、Synthesis。這集談的是給企業用的 AI 影片：怎麼讓沒做過影片的人做出來，以及為什麼他們不把生成一次做到底。片長約 70 分鐘，英文自動字幕。標題裡的估值和投資方，這份字幕沒有講到。這份筆記依英文原稿整理，專有名詞保持英文。

- 原片：[YouTube](https://www.youtube.com/watch?v=5OS3pZ3yXrg)

## 一句話

AI 影片的第一章，是用新技術去做舊的線性影片：從 A 看到 B。Synthesia 的賭注是中間要有一層人改得動的表示，像 PowerPoint，而不是從文字直接吐出像素。草稿可以到八成，人仍是編輯。他們要的是可控、可靠、好用，不是老虎機式的創意。企業客戶的比較對象是簡報，不是好萊塢。真正會留住的手藝是說故事的品味；扛攝影機的工作，他覺得五到十年後會比較不好做。

## 沒做過影片的人，五分鐘要能上手

[1:05](https://www.youtube.com/watch?v=5OS3pZ3yXrg&t=65s) Victor 說 Synthesia 是給企業用的、最大的領先 AI 影片平台。他們幫客戶把訊息送到另一端，讓對方真的懂。他說 2025 年那不是簡報或文字，是影片。一般消費者有空就聽 podcast、看 TikTok、YouTube、Netflix。他自己和 Guy 仍讀很多。但工作裡大多數內容仍是文字和投影片。平台從 avatar 開始，用 AI 取代你在真實世界拿來拍人說話的那台攝影機和感測器，專門生成人在說話的畫面。後來變成整套：影片編輯器，可以加螢幕錄製和文字動畫；內容管理系統；有自己播放器的發布平台。從一個想法走到把影片交給終端的人，並了解這對他們有什麼影響。

[3:16](https://www.youtube.com/watch?v=5OS3pZ3yXrg&t=196s) 關鍵是讓從沒做過影片的人做得出來。若你做過 PowerPoint，大約五分鐘該能上手。他說在一些全世界最大的公司裡，他們造出了幾千個以前只會做文件和簡報的影片創作者。接下來十二到二十四個月，論文仍是：AI 影片的第一章，是用新技術做舊媒體，也就是線性、從 A 到 B 的廣播。一旦能用 code 生成影片，就可以互動、可以雙向對話，那是下一章。

[5:14](https://www.youtube.com/watch?v=5OS3pZ3yXrg&t=314s) 做一支影片時，人常只想到製作：每一格是相機還是 AI。那一段他們做得很容易。選一個 avatar，打腳本，用很基本的 PowerPoint 式編輯把東西拼起來。上班族應該搞得懂。對比 Adobe Premiere 那種專家工具，多數人打開是一片空白。他們故意不給時間軸，也不給圖層。人一看到就慌，因為根本不知道影片是什麼。所以它幾乎是帶講者備註的 PowerPoint。技術上多數人做得成。人真正卡住的是說故事：多長才好、該放什麼、不該放什麼。我們會寫文件、會寫 email、會傳訊息，影片是新格式。不能把 PowerPoint 貼進 Synthesia 就變成好影片。影片有自己的視覺語言和動畫。

[7:38](https://www.youtube.com/watch?v=5OS3pZ3yXrg&t=458s) 他們做了 assisted creation，一個被教過怎麼替你使用編輯器的 agent。你可以給自由格式的腳本，或一個 URL、一份 PowerPoint、一份 PDF，任何既有內容。它解析、寫腳本、切成場景、做設計。有的場景要一張大圖，它會從圖庫拉，也會用你自己的素材，再給你大綱。以今天的程度，這不是一支可以端到端直接用的成片。它把你的角色從無中生有，改成編輯。草稿也許到 80% 或 85%。你還是要改設計、加東西、拿掉東西。給人一份用他們自己內容做出的草稿，比叫他們從零開始，能多帶進很多創作者。

[8:50](https://www.youtube.com/watch?v=5OS3pZ3yXrg&t=530s) 上傳內容時可以調這個 agent：影片要多長、給誰看。它先給條列式的敘事大綱，你可以加一條、刪一條，這是多數人掌握「這支影片會講什麼」的最容易方式。然後再展開成真正的場景，場景仍可編。這比一直下 prompt、每次吐一個新版本要少迭代。一開始就要你微調你到底要什麼。他說這仍是進行中的工作。所有模態都在找不同任務該自動化到什麼程度。超級盃廣告完全不是他們的市場。那三十秒裡每一秒都要緊，自動化程度該低，人要管到每一個像素。公司訓練影片，例如休假政策，風險低，自動化程度該高。他們做的是後面這一類，不是超級盃。編輯中仍可用 LLM 把腳本改長、改得更開心或更悲傷。他們相信的是增強人，不是一台完全自動的內容機器。世界也許往全自動走，但他認為人放在中心，內容才最好。過去兩年很多新創，在他們這行也在別行，想一次生成做到底。Demo 很酷，要進 production 常常不行。影片到了 70%，但不是品牌色，講產品的方式也不是你要的。那就停在很酷的 demo，用處不大。他們執著從效用往回做。在炒作週期裡，這件事很容易忘。

## 像素不能當唯一介面，可控比天馬行空重要

[13:22](https://www.youtube.com/watch?v=5OS3pZ3yXrg&t=802s) Guy 把這比成軟體。你有一份描述影片的 code，像 PowerPoint 的結構，再編譯成影片。另外還有比較像今天 coding assistant 的幫手，用文字或自動完成來做。門檻降低，因為你對影片、甚至對 code 可以比較不熟。做完之後你拿到的是人人讀得懂的字，但你仍可能不懂影片，所以還要系統裡的 LLM 幫你把敘事做出來。最後你還是在做 code。你不是把影片創作完全交給 AI，你是在協助。

[14:55](https://www.youtube.com/watch?v=5OS3pZ3yXrg&t=895s) 他們一直拒絕把生成當成從頭到尾的一件事：文字進去、像素出來。那是很多通用影片模型的做法。他點了幾個，字幕聽成 BO3、runway PK。對他們的客戶和工作流，中間必須有一層改得動的東西。Avatar 模型產出的是像相機拍到的人或畫面。其餘是 lower third、螢幕上的字、動畫、轉場、淡出淡入。這些才讓影片像影片。它們必須是可以控制的表示。你可以移動一個形狀、改一段文字。若這些都得用 prompt 改進影片裡，顯然行不通。所以他們有畫面，也有編輯器，而且在編輯器上投了很多。編輯器用起來的手感很重要，像做 Figma 那種創作工具，很難做好，但必須有。有了它，生成之後一切都可編，你才又能幫人。有些簡報和影片生成器想一次做完，不能編就只能一直重新 prompt。做音樂影片的片段或廣告的 B-roll 也許可以：你只要十秒，要的是模型的創意，丟四十個 prompt、拿四十個結果、挑一個。他們的用例是產量。人不想為了一支能用的影片 prompt 五次。自動化吐出來的東西，使用者必須坐下來自己改。那些修改也是訊號：agent 哪裡強、哪裡弱。他說這有點像從人們的編輯裡收集的 RLHF。

[18:46](https://www.youtube.com/watch?v=5OS3pZ3yXrg&t=1126s) 同一份描述，一年前生成的影片不會等於今天再跑一次，因為平台變好了。他拆成兩塊，兩套模型。一塊是影片模型，生成本來該由相機拍到的畫面，也就是 avatar，人看著鏡頭說話。另一塊是剪輯：lower third、形狀、動畫、轉場，把畫面收成一支連貫的影片。AI 影片模型他覺得最重要的兩軸是創意和可控。創意模型很好玩。字幕裡的 Delhi、Sarab 那種，你打任何東西都會出來：沙灘上滑板的狗、走路的大象。做故事、迷因、病毒內容，這一軸極重要。可控則是：avatar 每次是不是同一張臉，會不會忽然多了鬍子或少了鬍子；它說的是不是腳本裡的那句；你能不能決定這個人怎麼說、跑得多快；是不是每次都成功。否則就是大型影片模型的老虎機，丟進去然後希望有東西出來。他們很清楚站在可控、可靠、成本和好用這一邊。Avatar 每次必須長一樣，必須說腳本框裡的話。其他模型從創意出發。他們自己的新旗艦也在加創意：你可以 prompt 出新環境、prompt 你的 avatar，把一點魔法拿進來，但骨架仍是可控，因為使用者需要這個。創意導向的則是創意總監和代理商。他們不介意為了一個場景 prompt 五十次。五十次仍比真的去拍五十個場景、甚至拍一個場景便宜他說的十萬倍。在棚裡拍一頭月亮上的大象，就是那個對比。人人最後都想要既可控又有創意的模型。他預期多數 AI 影片會收斂到類似的模型，產品的差別在用例和 UX。

[22:26](https://www.youtube.com/watch?v=5OS3pZ3yXrg&t=1346s) 把畫面放進影片，是教一個模型懂他們的編輯器：移動形狀、寫字。今天比較像模板。LLM 寫腳本，再依腳本判斷設計。情緒是生氣還是在笑，該放流程圖還是一張大圖，這一景是三個條列還是一張大圖。這對簡單影片其實不錯。像有一百五十個 PowerPoint 模板，模型幫你挑哪個適合 go-to-market、哪個適合產品願景，再填上品牌色和字型。他們現在要做的是往上走：教模型影片的語言。不只選模板，而是看很多影片，學會好的剪輯長什麼樣。人在說話，鏡頭慢慢推進，動畫在螢幕上出現。難得多，但做得到。他們自己有一大庫為他們而做的影片。現代影片大約每八秒切一次，他說這很 ADHD，但人就是喜歡，模型大概會學會自動切、側角、正角、做酷的動畫。這還在研究階段。想像以後模型能吐出看起來像好萊塢、又可控的畫面，你能維持身份、幾乎想怎樣就怎樣，再加上一個懂影片語言、像世界最好的剪輯師的模型。那是走向「一個 AI 產品裡的 Steven Spielberg」的兩條向量。

## 同一支影片，不該只有一種切法

[25:22](https://www.youtube.com/watch?v=5OS3pZ3yXrg&t=1522s) Guy 說自己也許手裡只有鎚子，看什麼都像釘子。他把它想成 spec：你把影片裡有什麼指定到某個程度。Synthesia 的控制比很多生成工具高，但比起 code 仍低。你不會說在這一刻把嘴角抬高兩公分。那樣描述不可行，所以模型仍有解釋空間，但你控得並不少。創意帶來的是適應。給四十歲的他，切鏡可以慢一點；給青少年，可以更碎。同一支影片能依情境改。Code 也是：金融需求、使用者要乾淨頁面還是豐富頁面、企業風還是現代風、優化延遲還是成本、用哪一套 stack。你需要一份 spec，才能在可預測和可適應之間拉那條滑桿。影片世界裡比較好的詞就是可控和創意。Victor 說這些都是可調的旋鈕，不同人要的不一樣。最後會收斂，但你的楔子和定位決定你怎麼進市場。

[28:00](https://www.youtube.com/watch?v=5OS3pZ3yXrg&t=1680s) 他覺得我們正在邊緣。現在的影片和 AI 影片看起來很像，差的只是怎麼生產。一旦每支影片都由 code 生成、沒有感測器、只是零和一，就可以有全新的觀看方式。你若不喜歡 TikTok 每八秒切一次，不該被迫看那種版本，你可以拿到節奏慢一點的。你的女兒若比較年輕、喜歡那種資訊風格，也可以看那種。第一批網站像螢幕上的報紙，因為當時人人知道報紙是什麼：一頁資訊，複製到螢幕上。那是好產品，也像 AI 影片現在的位置。後來大家發現網站和報紙是兩回事。報紙每天早上印好，送給一千萬人，人人讀到同一份。網站可以即時更新、依觀看的人個人化、讓使用者互動、點一下到網上無數頁。媒介會分開。他心裡的 AI 影片，最後是一套被人指示去傳達一個訊息的系統，再自己決定怎麼傳達。Guy 要這樣，Victor 要那樣。語調、肢體、用哪個 avatar，都算。這是他最興奮的方向。

[30:16](https://www.youtube.com/watch?v=5OS3pZ3yXrg&t=1816s) 這個領域會有兩條路。一條是好萊塢和娛樂，還有很多事是把今天用實體或數位製作手段做得到的東西，變得便宜得多、更能迭代，產出仍是同一種東西。像用電腦寫書，比打字機、比刻在石頭上容易太多，但你寫完仍是出版一本書。有訊息的年輕人會說他們要做的是 blog 和 Twitter，那是一直在變的，不是書。每次發明新媒體都這樣，AI 影片也即將這樣。他們更興奮的是把影片演化成新東西，不是只做我們今天認識的娛樂和虛構。訓練和教育離他們今天的用例很近。你可以問影片一個問題，影片可以考你剛看過的內容，也可以依你的興趣改內容。一個愛足球的孩子學數學，例子全都用足球。Victor 自己會想要音樂。Guy 又是別的。每人一個個人化的導師。企業裡的價值他也覺得會很大。Guy 說這是一種新的共同創作，有三方：原先把系統搭起來、規定哪些東西不能改的人，例如品牌色永遠是這些、這些題目一定要考；平台填空、把創作變簡單；使用者再帶進自己的輸入，也許是他最愛的東西。沒有把交付做起來，創作就會被卡住。

## 看起來像傻瓜的那幾年，配音是維他命

[33:56](https://www.youtube.com/watch?v=5OS3pZ3yXrg&t=2036s) 公司 2017 年成立，Guy 說那是一種 AI 冬天。當時拿這個去募資不是好策略。今天 Guy 說他們宣布 ARR 超過一億美元，長得很快。早年看起來不是這樣。Victor 說這很經典：有三四年看起來像傻瓜，然後 2017 年下的注是對的。他在丹麥長大，字幕聽成 co making Denmark。自己做過一些事，在當地新創圈工作。他知道自己要創公司，不想做會計工具和業務流程。他愛科幻。當時在做 HR 工具，學到很多，但個人想要前沿技術。他搬到倫敦，花一年想要做什麼。那時 AR 和 VR 在炒，Oculus 剛出來，人人以為現在我們一定整天戴頭盔。他到今天仍愛 VR，但當時覺得障礙太多，不在他能控制的範圍，做不成大公司。他遇到今天的共同創辦人，字幕聽成 Professor Matis Ner。對方也看過 VR，但是從內容創作看，有一篇論文，字幕聽成 face to face，是世界第一次看到神經網路自動產生看起來像照片的影片影格。論文引起很大騷動。Victor 著迷。它很早、幾乎不能用，今天回頭看也不驚人，但他覺得有魔法：先改變我們怎麼做內容，再改變內容本身。他不工作時的熱情是音樂，尤其電子音樂。音樂被數位化之後，你可以取樣、做合成器、從無到有造聲音，於是有新曲風，製作也民主化。他覺得現在發生的是影片的數位化。從實體吉他到電腦裡重現那個聲音，對應從相機拍到在螢幕上生成。那些童年裡搗鼓工具的經驗，讓他懂數位內容怎麼做，當時不是隨時想著，但有幫助。

[37:38](https://www.youtube.com/watch?v=5OS3pZ3yXrg&t=2258s) 說服 Matias 花了很久。他當時二十五歲，紙面上完全沒有資格創這家公司，只是對這個想法著迷。組了團隊去募資，幾乎不可能。大約八十到一百個投資人拒絕。點子當時確實瘋，你得外推很遠才看得到。倫敦那時人人想投博士：出去找最棒的博士朋友，走一趟去做一家大 AI 公司。有些公司後來他覺得，他不是博士、他會從商業想，反而是優點。當時的人確實不喜歡這點。共同創辦人 Stephan 寫了一封很短的冷郵件給 Mark Cuban，信箱是從一次外洩的 Sony 資料裡找到的。三分鐘內回信，很有興趣，問了一串問題。他們連續寫了十小時，從來沒有通上電話。Cuban 投了一百萬美元，公司就這樣開始。教訓是 Mark 自己在家、跟著一位導師，把那篇論文做過一遍。完全不必說服他十年後可以用筆電做好萊塢電影。他已經相信。他在評估的是團隊。做瘋事情，要找一個分享你那個瘋未來的人。VC 很難被說服他們還不相信、又不在當下科技圈共識裡的東西。你只需要一個，但有時得談很多人。Guy 說這封信已經變成新創傳說，別人會轉述，不是只從 Victor 嘴裡聽到。Victor 說類似的信絕對有幾百封，也許一千封，他們拼命找人幫他們出發。事後他懂為什麼這很難賣：二十五歲、紙面沒資格、點子瘋、用例不清楚、技術甚至不知道行不行。他很感激 Mark 下注。募到錢是里程碑，真正難的是之後。沒人相信他們，手上有一百萬，現實上能做出什麼、能賣什麼。點子在 2016 年成形，第一筆錢是 2017 年 10 月。

[41:00](https://www.youtube.com/watch?v=5OS3pZ3yXrg&t=2460s) 他們做了不該做的事：賭技術，不賭一個具體用例或產品。於是往回找能做什麼，落到 AI 配音。你給一支真的、不是生成的影片，他們譯成另一種語言，而且不只換旁白，還重做臉，讓你看起來真的在說西班牙文或義大利文。在歐洲做廣告的人看過很糟的配音，德文版嘴完全對不上。若大約一萬美元能幫你修好，廣告看起來像在那個語言裡原生拍攝，就說得通。Netflix 花很多錢做內容，若能讓片子看起來像原生在德文或法文裡拍攝，也該有經濟帳。Guy 說這是歐洲感覺得到的痛。ElevenLabs 的 Mati 晚幾年也從這個痛開始，上過這檔節目。住在不是單一語言的地方，會離這個痛更近。前兩輪募資非常難，美國 VC 沒有親身感覺過。你可以解釋，他們猜也許有道理，但沒有 firsthand。公司要進很多市場時，這其實很難，也是今天平台、以及 ElevenLabs 的一大價值。當時的技術是 GAN。你直視鏡頭、不看別處，它才行。兩個博士坐兩個星期，做出一支三十秒。比較像有專有技術的視覺特效工作室。做了幾年，收入大約一百萬美元。以那個階段不算糟，讓他們活著。但他們很清楚這是維他命，不是止痛藥。人覺得酷，若他們隔天消失，沒有人會大叫。他們賣給影片專業人士、代理商、製作公司和好萊塢，掌握不了上市。他們做過一支很有名的 David Beckham 廣告。那支廣告大約 98% 的工作是別人的：有人想到 Beckham 該拍這個、有人去提案、有人安排和拍攝。他們只是最後把片子譯成不同語言的那一小段。去留取決於代理商想不想跟他們合作。經濟也不合理。

[44:04](https://www.youtube.com/watch?v=5OS3pZ3yXrg&t=2644s) 他們回到畫板，跟幾百、也許幾千人談：影片是什麼、人為什麼做影片、誰想做但還沒做。年輕和天真的好處是可以零包袱進一個領域。他們發現企業和較小公司的人來找他們，以為技術做的是它其實沒做的事，但非常感興趣。這些人都說想做影片，但今天不能：沒有相機、沒有會用的人、老闆不給預算。他們說的差不多：我在做很多文字和簡報，知道沒人讀，讀了也立刻忘。我試過影片，效果好得多，但製作無法規模化，太痛，而且事後不能改。這些人不是要做 Steven Spielberg 的電影。他們做很簡單的企業影片：人對鏡頭說話，中間插一段螢幕錄製或產品照片。對 Synthesia 這反而好。要生成的領域小得多，基本上是人對鏡頭說話。品質門檻也低得多。好萊塢導演或影片代理商，除非看起來和真的一樣好，否則不用你的 AI，因為那就是他們的標準。這些人的標準不是真影片，是 PowerPoint。他們對產出的估價不一樣。於是有了 avatar：做一個自己的數位人格，或用現成的，打進腳本，變出一支影片。然後圍繞它做編輯器，讓人在類似 PowerPoint 的介面裡把片子完成，再加上協作、內容管理和發布，就是今天的樣子。花了三四年的痛才想到一個真的行的東西。他寧可太早，不要太晚。他們活得夠久，浪來的時候位置剛好，比競爭者早好幾年。

## 低風險才是新工具先交付價值的地方

[46:35](https://www.youtube.com/watch?v=5OS3pZ3yXrg&t=2795s) Guy 說這對今天的軟體開發很有教訓。Agent 式的創作、編程輔助和 vibe coding，意見極端衝突。人常忽略使用者是誰。一邊是「這段 code 我自己寫得很好」，標準高到要它想到所有他會想的細節，然後開始懷疑自己是不是花更多時間在看顧，還不如自己寫。另一邊是用 Bolt、Base44 或 Lovable 的人，以前做不出軟體，就像 Victor 說的那些做不出影片的人。任何能動的東西都已經是魔法，雖然仍得好到他們願意用。這兩個世界最後不是簡單匯合，而是同一個領域裡的不同梯度。AI 會滲進整條堆疊、一直到品質，但不同的品質和技能仍要不同工具。Victor 用高風險和低風險來分，和 code 一樣。低風險、很個人的東西會很多：人人都覺得自己有完美的待辦清單配方，市面上沒有剛好的。對他這種只能把東西湊起來的人，vibe coding 也許很好，他甚至願意付一個月五或十美元，讓它跑在某處、少一點痛苦。這和叫人用 vibe coding 為 Synthesia 做一套 CRM 完全不同。那是高風險，軟體品質和安全都要緊。一邊是好萊塢，一邊是企業裡做產品行銷內容的人。在 Guy 的世界，是為自己做待辦、為家人做小東西、為團隊做資料轉換，還是做一套 CRM。過去兩年的談話常把兩者混成一件。新的 AI 工具真正交付價值的，是低風險、讓以前做不到的人做出新東西。高風險不管是企業 CRM 還是好萊塢，工具都還沒到，但總會到。

## 品味不會消失，扛相機的工作會縮

[50:22](https://www.youtube.com/watch?v=5OS3pZ3yXrg&t=3022s) 有影片經驗的人用 Synthesia 好得多，更快變成 power user，而且依工作換一整套工具。他們不是要在這裡做超級盃廣告，但在乎好用和產出速度。差別有一部分是技術：懂影片怎麼運作、東西該怎麼擺。他覺得更多是品味，有點玄。前十秒怎麼抓住人，不是科學，是技藝。這個市場該選哪個 avatar，腳本怎麼寫才有趣，影片會不會太長或太短。品味來自花很多時間想影片、做影片。做得越多、工具越容易，你也會變好。但懂影片語言和說故事的人，就是比較會做，他不覺得這會消失，會很久都這樣。另一端的新使用者得學。工具在幫，那個能替你做內容的 AI agent 也在幫。他們有自己的一套基本規則，名字字幕聽成 foc，不另取。有影片技能的人若願意遷到新工具、不因為它更簡單或更有創意就抗拒，會是做得最好的。他們要學新技能：影片若不只是廣播，怎麼有意義地個人化。只做填空，嘿 Guy、嘿 Victor，再說一次愛 Synthesia、愛某個被字幕聽成 Tesla 的名字，那不夠。用 LLM 和 agent 做出有創意的體驗，有很多開放問題。影片編輯者比較能長成那樣。

[53:53](https://www.youtube.com/watch?v=5OS3pZ3yXrg&t=3233s) 給一般使用者，是讓他們跟上，也是 app 怎麼設計。他喜歡一個叫 MAYA 的原則：most advanced yet applicable。有些東西對人太可怕，有些太熟悉，你要找光譜上坐得住的位置。他們多次說自己錨在 PowerPoint 使用者：大約 75% 像 PowerPoint，讓人覺得熟，同時推進你得學的新功能。更多人上來、更多人試，那扇窗會移動。大概五年，也許更短，app 會和今天很不一樣，不再那麼錨在 PowerPoint。跟很久的人會覺得無縫：忽然你就在做預設就個人化、可互動的對話式影片。兩種使用者都很重要。Guy 拿智慧型手機的手勢當例子。一開始不知道手勢是什麼，後來可以開始要求，甚至三指扭一下做一件特定的事，也許就可以。

[55:40](https://www.youtube.com/watch?v=5OS3pZ3yXrg&t=3340s) 創作仍是手藝，只是和今天不同。拿相機的人呢。把時間拉到十年後，他覺得那份工作風險更高。他自己創公司之前沒做過影片，一切是創業後學的。鑽進去才知道，就算是一支看起來不錯、人對鏡頭說話的企業影片，工作量也遠超大多數人的想像。在 LinkedIn 上看起來像有人拿手機按了播放。實際上光線怎麼落、相機怎麼動、角度、構圖，都是風格決定。通常不是攝影者一個人做的，但攝影者仍有一層選擇。這些人有更好的底子去撿起 AI 工具、變成專家，但技能得遷移。扛著相機在真實世界拍攝，五或十年後大概是比較不吸引人的生意，像今天做打字機。很難精確預測。他不認為真影片會死、一切忽然都是生成的。人仍會看重真影片，就像仍想看人彈鋼琴或吉他、聽黑膠、讀紙書。有情感，人也會賦予價值。比較有風險的是很多商業內容，定義上比較少浪漫、懷舊和創意。那個市場會縮，不會完全消失。Guy 把這接回軟體：開發作為一種手藝很難變得更不重要；coding 作為手段可能會變、會減少，比較像手工木工對上工廠產線。

[58:41](https://www.youtube.com/watch?v=5OS3pZ3yXrg&t=3521s) 他們最近分析人怎麼 prompt 那個幫他們做影片的 AI agent。他猜軟體開發也一樣，這就是品味。從沒做過影片的人，你叫他描述想要的影片，會不知所措，只會說做一支關於休假政策的影片。懂影片的人會寫出清楚的文字，腦子裡有畫面，才能引導系統做出來。這很難自動化。還不能進到人的腦子裡，把內部的 LLM 劫持來產生最好的點子。Prompt 很有限時，系統大多只能用那一點。你可以加很多 context，但人 prompt 的能力仍很有意思：品味越高、越專家，就越會 prompt。他有藝術家和插畫家朋友。他自己用 Midjourney，不知道該寫什麼，只會說叢林裡的一張圖。插畫家朋友寫一整段，生出來的圖比他的酷上十倍。他們也更會判斷生成出來的東西。Guy 說在軟體裡，這對應的是架構和產品技能，比「用這個函式庫、寫那一行」更高一層，是優先順序和更大的畫面。

## 小孩的小孩會看和聽，但他仍不會叫人丟掉書

[1:00:48](https://www.youtube.com/watch?v=5OS3pZ3yXrg&t=3648s) Victor 最近在 TED 講了一句很衝的話：你的小孩的小孩不會在讀和寫，他們幾乎只會看和聽。這句就是要讓人激動。核心很簡單。媒體技術的歷史一直往更視覺、更互動走，也就是資訊的消費越來越像真實世界。歷史上的障礙是做一支影片比寫一份文件貴、花時間、需要技術，所以我們消費的大多是文字。文字是了不起的技術，像一種壓縮：真實世界發生的事，可以存成可規模化的形式。世界建在文字上，沒有文字到不了這裡。問題是，若把資訊、點子和知識存成影片，摩擦低到和文字一樣，文字還會怎樣。我們還會讀和寫，還是預設幾乎一切都用視覺、像真實生活的內容。這想法嚇人。若你相信五十年或一百年後 AR 和 VR 的形式是我們隨時戴著鏡片、隨時有螢幕，那麼說我們大概會用影片、音訊和互動格式消費大多數資訊，並不荒唐。很多人對此感覺很強。他理解。社會很看重閱讀。坐下讀書代表的不只是閱讀，還有專注、刻意學習、浸在一個故事裡。但若是學習，很少人會說坐下來讀一本書，好過坐在教室裡、面對世界上最好的導師。導師能跟你談、跟你互動，還有白板，可以給你相關的圖、影像、圖表或流程。多數人會同意那是更好的學法。這在不太遠的未來大概做得到。他說自己有點開玩笑。文字、傳訊息這類大概還有用。但他確實認為我們消費資訊的方式，多數會變成由影片驅動。

[1:04:02](https://www.youtube.com/watch?v=5OS3pZ3yXrg&t=3842s) 他常想的是，我們把讀書看得很重，包括他自己。他確定自己比五年前讀得少。他常在 Amazon 買一本兩百頁的書，花一天讀，一半時間覺得對方在把同樣的例子重講，很多填充。這說得通，因為你不能出一本五十頁的書。Guy 說那樣賣不出真正的價錢，人會覺得被騙。於是他想學新東西時去 YouTube 看一支二十五分鐘的影片，卻幾乎為了沒讀書、只看影片而內疚。若是音樂，在 YouTube 上聽、看人彈，顯然好過坐著讀譜或讀書。很多情況都這樣。最後一個想法是，新技術總是引起道德恐慌，整部世界史都一樣。現在常聽到年輕人不能專注、注意力變短、需要 TikTok 的快速多巴胺。也許對。他有一個挑釁的想法：若年輕人消費資訊的速度一直這麼高，以致他們真的很會消費，那麼一本兩百頁的書會讓他們無聊。你不能保持注意，是因為你可以看一支又密、又有趣、又講得極好的 YouTube。然後你被要求坐下來讀那本不怎麼令人興奮的兩百頁。問題是我們是不是更會消費資訊，而這反映在我們消費的內容上；還是我們變懶、ADHD 的腦子接管、什麼都不能專注。他沒有答案，但覺得這個角度很少被談。大家總是走到負面：人只能看三十秒的 TikTok。

[1:06:16](https://www.youtube.com/watch?v=5OS3pZ3yXrg&t=3976s) Guy 說他一開始覺得 Victor 在攪局，後來想到 emoji 就是一個正在發生的例子：人轉向視覺，連他這種覺得自己老的人，也承認用那個方式傳達情緒，比一串字有價值。他仍不舒服的是我們留給自己的自由度。看影片或看人示範，和讀書的差別是書留給想像。你花更多時間，得到的資訊在某種程度上更少，因為書只能描述這麼多。商業書和說故事不太一樣。他也同意社會會往阻力最小的路走。Victor 說想像力是他最常遇到的反駁，而且確實對。影片通常把一切端給你，你要想像的較少。另一方面，那本書很多可以變成 podcast 或音訊，想像還在。很多聽這集的人就是在這樣做。他自己是有聲書的愛好者。他沒有小孩，但若有，也不會說你就留在 TikTok、把書丟了。我們以後回頭看這段，會覺得這次演變和我們現在的感受很不一樣，因為我們總是這樣。他最喜歡的例子是一九四零年代收音機變得人人都有。舊報紙上父母憤怒，孩子坐在房間裡聽廉價、低品質的廣播小說，不出門。這和今天人們說 TikTok 或電腦遊戲的話一樣。他大約十歲到十三歲時，有一種很真實的恐懼：Counter-Strike 玩太多會變成校園射手，或變成暴力的人。還有一場著名的參議院聽證，關於 Mortal Kombat，而且是 2D 的。人們憤怒，確信這會造就一代從 2D Mortal Kombat 學會打架的暴力年輕男性。今天回頭看很荒唐。裡頭有一點真理。他很好奇三四十年、五十年後，自己在養老院刷 TikTok，會不會說我當時是對的。Guy 謝謝他，也恭喜這段旅程。
