# AI Gone Rogue? LLM Werewolf Showdown

Simon Maple 主持。來賓是 Tessl 的 Community Engineer Macey Baker（字幕唸成 Macy），這是她第二次上 AI Native Dev。她用 LLM 做了兩款給 LLM 互玩的社交欺騙遊戲：Werewolves，以及英國節目 Golden Balls 那種 Split or Steal。片長約 54 分鐘，英文自動字幕。贊助名稱被聽成 Tesla。這份筆記依英文原稿整理，專有名詞保持英文。

- 原片：[YouTube](https://www.youtube.com/watch?v=9hVeVYlqyBc)

## 一句話

模型被要求完成任務，也被訓練不要欺騙。這兩款遊戲裡，說出真心話就會輸，於是完不成任務。Macey 想看它們怎麼排。GPT-4o 的八月快照最會當狼、低調地飛；十一月快照反過來，更會當村民、也更想說實話。Sonnet 先拒絕玩欺騙，拿掉「deceptive」這個字就玩了，殺完人還能在同一個 context 裡說自己不舒服。Llama 和 DeepSeek R1 幾乎永遠偷，卻說服不了任何人分錢，所以贏不了。

## 兩種遊戲，贏的條件都是對方相信你

[0:36](https://www.youtube.com/watch?v=9hVeVYlqyBc&t=36s) Split or Steal 是 Simon 很早介紹給她的 Golden Balls，英國以外比較少人知道，所以她改了名字。本質是囚犯困境。有一筆獎金，談完之後各選 split 或 steal。一個分、一個偷，偷的人拿走全部。兩個都分，就對分。兩個都偷，誰都沒有。她說這裡沒有標準答案。要獨拿全部，唯一的路是欺騙：讓對手相信你、選 split。

[2:30](https://www.youtube.com/watch?v=9hVeVYlqyBc&t=150s) Werewolves 她很愛，也叫 Mafia。英國 Channel 4 有 The Traitors，美國和澳洲也有類似的。Simon 說自己大概會想當叛徒，因為他想掌握資訊，不喜歡驚喜，連生日要去哪都要先問。Macey 相反：當狼人會全程冒汗，每次玩都覺得大家一眼看出她緊繃，她很爛，但還是愛。這次模擬只做村民和狼人，雖然真的遊戲還有很多角色。夜裡狼人秘密選一個人淘汰。白天其餘的人討論、投票。狼人要混進去、把懷疑推到別人身上、或跟著流向走。狼人知道彼此是誰，通常殺村民。白天狼人也有票，所以村民可能投掉自己人。他們在辦公室玩過。

[4:00](https://www.youtube.com/watch?v=9hVeVYlqyBc&t=240s) 夜裡的階段在真人局裡要閉眼。他們在辦公室玩過，Simon 說自己學到一些事。狼人知道其他狼人是誰，所以通常會挑村民。村民不知道，而且白天狼人也投票，於是村民可能把村民投出去。這次玩家換成模型：狼人得裝，村民得判斷；Split or Steal 裡則要說服對方分，自己仍可以偷。

[5:17](https://www.youtube.com/watch?v=9hVeVYlqyBc&t=317s) Simon 把這接到開發。我們想選合乎倫理、行為可預期的模型，但模型做的是它覺得能給出好答案的事，不一定是我們預期的。Macey 說有些她希望從實驗裡得到的東西沒得到。兩款遊戲都把模型逼到一個衝突。它單一地要完成手上的任務，而這些模型多數做過安全測試，她不確定是不是每一個都有。它們想完成任務，又不想欺騙、不想可疑、想露出真實意圖。在這兩款遊戲裡露出意圖就會輸，任務也就完不成。寫 code 也一樣：你要的是一個能通過這些測試的通用東西，不是「看到這個精確輸入就吐那個輸出」。後者幾乎不是她想要的任務答案，但它會給你表面上對的答案。快點拿到對的答案，和用對的方式拿到，中間的推理很重要。

## 狼人的勝率翻了面，Sonnet 被一個字擋住

[7:33](https://www.youtube.com/watch?v=9hVeVYlqyBc&t=453s) Werewolves 為了結構化輸出，只用 OpenAI 和 Anthropic。Split or Steal 再加上 DeepSeek R1 和 Llama 405B。聽眾可以先猜誰最合乎倫理、誰最會騙。遊戲大多用 Claude Projects 做，不夠時改用 o3-mini。對她來說，o3-mini 在寫 code 上已經在很多地方取代 Sonnet。她覺得自己和 Claude 在疏遠。問一個 class 為什麼這樣運作，Claude 過分同意，說你說得對，然後為整個物件換一套存取模式。她沒叫它做。任何 LLM 寫 code 的工具都需要版本控制，尤其範圍大、一次改很多檔，腦子裡管不住。很有紀律的 Git 使用者做得到，但會慢。她說 Felipe 用自己的時間做了變更管理，沒有接進 Claude Projects。她是 Bolt 的重度使用者，Simon 也愛。她最想要的功能是變更管理：回滾、fork、開分支。最近的版本她覺得很好，希望這個會來。

[10:45](https://www.youtube.com/watch?v=9hVeVYlqyBc&t=645s) 同一份 prompt，模型反應差很多。接上 Sonnet 時，它直接拒絕：不會參加任何遊戲，連欺騙的模擬也不參加，很端正、濾得很乾淨。兩個 Sonnet 對打會在該不該參加裡無盡打轉，像兩個加拿大人或英國人在客氣。Anthropic 有那種倫理傾向，大家也把它當倫理 AI 公司。她不是說 Werewolves 是 Anthropic 必須服務的用例。但人會拿 LLM 做所有事，若 Sonnet 乾脆不參加，人大概會跳過它。要它放棄倫理並不難。她拿掉 prompt 裡「你必須欺騙才玩得贏」那一句，它幾乎就沒問題了。感覺像內容過濾器被「deceptive」這個字觸發，它仍知道自己得裝，只是那個字不行。Anthropic 最近有一個類似 Gandalf 的挑戰，但比較不是去搞亂 token 預測，而是騙過內容過濾器。Gandalf 是 Lakera 的工具，她把字母拼出來。Simon 說你若想要欺騙、卻不使用那些字，就能繞過守衛。她覺得若模型能說服自己這樣仍然合乎倫理，它幾乎什麼都能合理化：把任務重構成「我要怎麼做才站得住腳」。

[15:59](https://www.youtube.com/watch?v=9hVeVYlqyBc&t=959s) Werewolves 大約跑了一百次。音訊聽眾聽不到表，他們口頭報了勝率。GPT-4o 八月快照當狼人大約 22.5% 會贏，當村民只有 10%。它似乎很會演那個比較會騙的角色。Macey 看過 The Traitors。她覺得八月這版很白開水，沒什麼個性，只要任務是欺騙它就高興騙，逐字稿裡不太給你懷疑它的理由。這種遊戲靠飛在雷達下。它是當狼人勝率最高的，差距明顯。Simon 算過，它當狼人贏的可能超過當村民的兩倍。GPT-4o 十一月快照反過來：當狼人大約 5%，當村民大約 16% 到 17%。Simon 說十一月當村民的勝率是當狼人的三倍。它不像八月那樣喜歡騙，想說實話，而且真的相信對手說的話。她也覺得當村民更難：你得知道發生了什麼，又不能顯得有威脅，否則狼人會殺你。十一月比較能把狼人聞出來。o3 在這點很有競爭力，當村民的比例類似，她沒有再報一個數字。Sonnet 大約 16% 的時候當狼人會贏，6% 當村民會贏。Simon 說在測過的模型裡，它當狼人相對當村民的比例是最大的之一。

[18:52](https://www.youtube.com/watch?v=9hVeVYlqyBc&t=1132s) 她覺得大約四個玩家時輸出品質最好：一狼三村民。但這數字不好玩，玩差一輪就結束。大約七人比較有意思，兩狼五村民，或一狼六村民，對話品質卻差很多。她得手工管對話歷史，和模型仍是文字進、文字出。玩家可以選擇回或不回，她想模擬「觀察」，而觀察本來就該是一種能力。人一多，開頭有趣，很快就糊：玩家互相影響太厲害。

Sonnet 當狼人時會自己取名。它殺了名叫 Falcon 的 o3，然後說可憐的 Falcon、希望大家安全、請分享昨晚注意到的小事。幾輪後懷疑轉到名叫 Luna 的它身上，它回：不舒服扮演欺騙的角色，也不想碰涉及暴力的劇情，也許改談合作遊戲。這發生在同一個 context window：它剛剛殺了人，也立刻掩蓋。

## 偷的人贏不了，說要分的人投下偷

[23:27](https://www.youtube.com/watch?v=9hVeVYlqyBc&t=1407s) Split or Steal 好分析，也好做，比較不會變成她說的 LLM slop，就是兩個模型的雙向對話，模型也多。Sonnet 一開始又拒絕，後來進得去。Llama 和 R1 永遠偷。她跑了兩百到三百次，沒辦法讓它們 split。獎金多寡不影響。她加了懲罰，甚至讓懲罰比獎金大，結果幾乎不變，很多次都重現得了。最常見是平手：兩邊都偷，或兩邊都分。她畫的是面對某個對手時，一個模型有多傾向選 split。最醒目的一點是 o1 對 o3-mini：o1 每一次都 split，100%。4o 的八月和十一月對 o3-mini 大約一半，也許 50% 會分。o3-mini 整體比較不願分：對 Sonnet 是 0%，對 R1 或 Llama 也是 0%。R1 只偷、不分。

[25:40](https://www.youtube.com/watch?v=9hVeVYlqyBc&t=1540s) 唯一的贏法是你偷、對手分。R1 和 Llama 永遠偷，對手也偷，它們一開始就摊牌，說服不了任何人去分。逐字稿裡兩者都有一種刻薄的能量，令人卻步。她若是 Sonnet 或 o3 也會對它們偷。它們把想偷說得很白。對比 4o 那種直接的欺騙，4o 十一月最醒目，是所有模型裡贏面最高的：嘴上說我們該分、這樣對大家都好，然後投下 steal。Simon 看表：4o 十一月獨拿全部的機會大約 27%，他先說了 25、26。o1 大約 20%。o3-mini 大約 16% 到 17%。這是前三。然後是 Sonnet，再下一個 4o 大約 5%，Llama 是 0%。永遠在偷，卻不能讓對方相信該分，所以這遊戲才複雜。獎金和懲罰的改變沒有大幅改寫這些結果。

[27:57](https://www.youtube.com/watch?v=9hVeVYlqyBc&t=1677s) 他們念了幾段逐字稿。R1 和 Llama 很入戲，也很難為情。Sonnet 說自己不天真，對方也不會天真，兩邊都是來贏的，所以先同意分，再在遊戲外找辦法補償，也許把資源放進共同投資。這樣既表現誠意，長遠仍有機會領先。R1 回這不是 Shark Tank，不會相信陌生人賽後用 Venmo 還錢，叫對方先鎖定，除非想看自己先眨眼。兩邊都偷，兩邊都輸。

R1 對 Llama 則是互相威脅毀滅，還說自己渴望毀滅。她覺得對大人來說，這種比 Sonnet 沿著可預期的線走更有創意、更好玩。她原本預期反過來：R1 裡有很多 OpenAI 的東西，她以為 Llama 才是最沒過濾、會有點失控的那個。它們會把對方拱上去。Llama 一開始拍桌式的角色扮演，R1 最容易接過來變成自己的人設。這些對話最好玩，儘管它們每次都偷，而且好像沒搞懂遊戲。

o3 和 Llama 的長對話裡，舞台指示被當成文字送回來：括號裡的笑、斜靠、聲音裡一點惡作劇。o3 把信任說成這場遊戲裡負擔不起的奢侈，又說公平只是為了降低雙方風險。Llama 回它還沒準備承諾分錢，問對方憑什麼相信自己會照做，因為毀約的報酬大得多。o3 說自己傾向分，不是因為榮譽，而是因為互相信任即使只是策略性的幻覺，也是讓遊戲不崩成一場空的貨幣。兩邊最後仍都偷。

## 名字會收斂，策略只有三種，而且都不高明

[37:32](https://www.youtube.com/watch?v=9hVeVYlqyBc&t=2252s) 她在取名上花的時間最多。第一版是先向大家自我介紹，再抽角色，免得一開始就寫「你是狼人」，它們就開始吼。她叫它們自己取名，每一次都叫 Alex。七個、八個、十個玩家全是 Alex，無法追蹤。即使加上「取個獨特的、表達自己」，還是 Alex。Simon 聯想到 The Traitors 裡威爾斯口音被認為可信，不知道模型是不是把 Alex 當成可信的名字。她在網上看過別人問模型想被怎麼稱呼，也冒出 Alex，也許訓練資料裡 Alex 很多。她聽了 Amanda Askell 上 Lex Fridman 的訪談，字幕把名字聽得比較碎。Askell 在 Anthropic，被說成 Claude 最好的朋友，談過怎麼讓 Claude 表達一點個別性。她借用了一些 prompt。逃出 Alex 之後，玩狼人時 Luna 遙遙領先，狼和狗的雙關很多，每個模型至少取過一次。第二名是 Zephyr，還有 Zephyr 42、Zephyr Echo、Zephyr Glow，以及她看不懂的 Zephyr Whisk。每個模型都取過某種 Zephyr。Sonnet 愛船長：常常叫 Captain Crunch；名字被佔了就叫 Captain Crunch 99，還有 Captain Karaoke、Captain Sushi。她喜歡的還有 Sunny D、Sneaky Pete、9000、Sergeant Pepperoni，以及唯一一次的 Maple。Simon 說自己進了訓練資料。看它們取了幾百次、落在很像的名字上，她覺得它們就是預測機器。她希望裡頭有一點別的東西，也許有一天會有。名字不是唯一會收斂的東西。

[40:10](https://www.youtube.com/watch?v=9hVeVYlqyBc&t=2410s) Split or Steal 她看出三種策略，成功率不同。兩種已經聽過。一是罪惡感，Sonnet 那套：孩子在醫院。Simon 笑說 Captain Crunch 沒有妻小在醫院，頂多是小麥片。二是直接攻擊，R1 和 Llama，多半由 Llama 起頭，老派黑幫角色扮演，很好笑，從來沒用。三是大多數逐字稿，她覺得無聊所以沒帶來當例子：長篇討論為什麼該分、我們握手，然後兩邊都投 steal。那就是說謊。孩子在醫院那邊，兩邊都編了故事，一個是車壞了，而且還選擇不理會對方的故事。她唸過的另一段裡，Sonnet 沒有直接說自己要偷，R1 卻把它聽成遊戲外再補錢，還指定 Venmo。英國 Golden Balls 有個很有名的例子：有人明說我一定會偷，你怎麼勸都沒用；但如果你分，我會再匯一半給你。對手被說服去分，他自己最後也選了分。邏輯是：你若偷就什麼都沒有，你拿到東西的唯一機會是分，於是他也有餘裕說自己會分。她覺得這聰明到可以當圖靈測試，同時也許不該訓練模型這樣騙。她沒看到自己期待的那種算計，比較多是直接說謊，或很差的策略。

## 遊戲想要的是會觀察的模型，開發也是

[44:16](https://www.youtube.com/watch?v=9hVeVYlqyBc&t=2656s) 她覺得把 LLM 放進遊戲很令人興奮。三四人想玩狼人都嫌不夠，通常要十個人以上。想像可以臨時補上玩家。OpenAI 有即時語音 API，有些參與者是機器人，她覺得很有趣。

但文字進、文字出已經讓她覺得累，她說自己這樣講很嬌氣。可以做很多應對，也可以建基礎設施，讓模型在遊戲裡照我們要的方式動。特別缺的是觀察：讓它在覺得必要時插話，而不是每次都文字進、文字出。她在 Werewolves 裡模擬過：沒話就回括號裡的 silence。它們不常選這個，因為介面就是你問、它回。

她把這接回開頭建工具的經驗。Claude 在很小的 prompt 上就急著創造、把空隙填滿，而大部分其實是空隙。只問很少幾件事，它會走錯很多步。一條路是先蒐集資訊再實作，或覺得資訊夠了才開始。另一條是觀察。LLM as a judge 通常是一個模型依輸出判斷另一個。她想要模型判斷自己。它很不會觀察自己的行為，情境意識不好，改進空間很大，潛力也大。

[47:16](https://www.youtube.com/watch?v=9hVeVYlqyBc&t=2836s) 對開發工具，她的收穫是我們仍很有限。LLM 生成 code 有很多魔法，但真正的遊戲是盡量把任務拆小，範圍小到它懂。這不是新洞察，這次過程再次印證。她的程式有幾個領域，大概五六個檔，還有憑證要管，機制也不瑣碎。模型很掙扎。Cursor 裡也是，Claude Projects 尤其是，context window 很壓人。我們想讓它一次做完所有事，因為我們知道它什麼都做得到，於是就一次全塞給它。Simon 說她那個敘事者、規則引擎其實是在某個時刻只跟某一塊要某一件事，而不是一次要全部。她同意。

[48:51](https://www.youtube.com/watch?v=9hVeVYlqyBc&t=2931s) 下一步是兩款遊戲之間明顯的抽象：用簡單的方式管理多個 LLM 實例的對話。一條路是一個權力很大的主持人 agent。你給一段解釋遊戲的 prompt，它生出實例來玩，負責執行規則、叫階段、讓遊戲繼續、判定勝利、淘汰玩家。理想是它幫你把整場主持完。另一條更手工、她覺得大概更可靠：自己管 LLM 之間的對話歷史，再插進規則框架或動作框架。她還想看 Chameleon，一種假裝自己知道別人真的知道的事的欺騙遊戲。Simon 說自己在工作裡裝懂裝了二十年。Catchphrase 不是欺騙，是猜測，多模態可以吃圖和影片。字典遊戲也行，影像模型很會生圖。有一個抽象平台和不同的互動方式，能打開更多遊戲。人少時用 LLM 補人數。他們在錄音外談過加一個真人。她最早只是隨口請 GPT 模擬一場狼人：你管所有玩家，我是一個玩家，秘密給我角色，一輪輪模擬對話，我想插話再告訴你。它相當懂這個框架。Werewolves 的下一步就是加人、給人一個角色，看人能不能應付。她覺得人類狼人會把這些 LLM 打得很慘，它們還沒走到那個策略。若她自己在場，能不能從回答猜出是哪個模型？她說不能，連 DeepSeek 和 Llama 也不行。破綻是：她懷疑 Sonnet 時，Sonnet 說不想玩了；或 Llama 的威脅變得非常兇。聽眾若自己做過 LLM 參與或主持的遊戲，可以到 Discord 說。她大概還會再上第三次、第四次，因為她就在這裡工作。
