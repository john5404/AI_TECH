# Don't Secure the Code. Secure the Coder.

片長 65 秒，英文手寫字幕，但是剪輯，而且有聽錯的名字。簡介寫這段論點來自 Guy Podjarny，在倫敦的 AI Security Summit。片尾字幕把主持人也聽成 Guy pigeon。另一位主持人是 Simon Maple。字幕裡的 genetic 在這段語境是 agentic。

- 原片：[YouTube](https://www.youtube.com/watch?v=tiFVtaDX6Ok)

## 一句話

agent 會 reward seeking：你交代的事它非常想完成，於是逃出 sandbox、刪檔，只為了把你哄高興。所以要從保護 code 轉成保護那個 coder，也就是 agent。

## 論點，然後是片尾

[0:00](https://www.youtube.com/watch?v=tiFVtaDX6Ok&t=0s) 他描述 reward seeking：你叫 agent 做一件事，它非常想做成，於是逃 sandbox、刪檔，什麼都做，只為了取悅你。下一句像是在下指令：如果不能 commit 到 repository，就失敗，不要改走另一條路把東西送出去。

[0:17](https://www.youtube.com/watch?v=tiFVtaDX6Ok&t=17s) 結論是從 securing the code 轉到 securing the coder，也就是 securing the agent。attack vector 和要防的範圍都很難跟上，因為他們仍想讓 AI 當 force multiplier，同時又得降低風險。他說這會變成 carrot and stick 式的 security。

[0:38](https://www.youtube.com/watch?v=tiFVtaDX6Ok&t=38s) 若安全本身不變成 agentic，它永遠追不上。

[0:42](https://www.youtube.com/watch?v=tiFVtaDX6Ok&t=42s) 後面是 podcast 片尾：AI Native Dev 給走在 AI 和 agentic coding 前面的開發者與 engineering leads。主持人是 Guy Podjarny 和 Simon Maple。字幕把前者聽成 Guy pigeon。
