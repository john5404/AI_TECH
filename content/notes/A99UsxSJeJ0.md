# The Hallway Track: Would You Trust an Agent to Send Your Email?

片長 99 秒，英文手寫字幕。走廊問答。簡介說地點是 AI Engineer SF。有人提到自己做的小程式叫 Simon EA。

- 原片：[YouTube](https://www.youtube.com/watch?v=A99UsxSJeJ0)

## 一句話

現在還不會讓 agent 不經你看就把信寄出。有人的做法是只寫草稿、不給 send。信一旦影響組織外面的人對你的看法，那條線就跨過去了，而且收不回來。

## 問答

[0:00](https://www.youtube.com/watch?v=A99UsxSJeJ0&t=0s) 開場有人說，寄信給岳母之前自己要在迴圈裡。另一個人來學的是 observability 和 deterministic models，想讓 AI 的結果比較可信，也想知道企業規模採用時，怎麼確認模型沒有還在 hallucinating，或 eval metrics 抓得到、看得到底下發生什麼。

[0:30](https://www.youtube.com/watch?v=A99UsxSJeJ0&t=30s) 有人說現在太多價值和資料流過 AI 和 harnesses，下一題是怎麼控制。也有人說自己已經有 20 個 loops，然後問：接下來呢？

[0:43](https://www.youtube.com/watch?v=A99UsxSJeJ0&t=43s) 固定問題是：你現在會不會信任 agent 不給你看就代你寄信？做 Simon EA 的人說它能讀信，但只寫信、留在 draft，沒有 send，每封出去前都自己看。另一個人說，工具再強，影響到組織外的人對你的看法時，那是重要的線，而且 non-reversible。字幕有一句聽成 retaining door，意思是這不是一扇轉個身就能回來的門。

[1:20](https://www.youtube.com/watch?v=A99UsxSJeJ0&t=80s) 例子回到岳母：如果 agent 讀了一整天日記，又要寫信給岳母，你會想在寄出前留在迴圈裡，而且要能把這種情況講出來。
