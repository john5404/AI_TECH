## 一句話

先全域安裝 CLI，用 help 確認，再 `tessl login`。瀏覽器確認 terminal 上的 code 之後，登入成功。最後還有一個查「我是誰」的指令，用來確認已經登入。

## 步驟

[0:01](https://www.youtube.com/watch?v=-mwv1JsTA9M&t=1s) 這支片是把 Tessl 裝到機器上。需要 Node 22 以上。用 npm 做全域安裝，字幕說參數是畫面上的 URL，沒有把字串念出來。

[0:14](https://www.youtube.com/watch?v=-mwv1JsTA9M&t=14s) 裝完用 help 檢查 CLI 能不能跑。字幕把指令聽成 tessle-help。
