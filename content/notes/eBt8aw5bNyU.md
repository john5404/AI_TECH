# The Hallway Track: AI Adoption Is Accelerating

片長 84 秒，英文手寫字幕。走廊裡幾個人輪流答。簡介說地點是 AI Engineer SF。沒有名字。

- 原片：[YouTube](https://www.youtube.com/watch?v=eBt8aw5bNyU)

## 一句話

金融這邊有人說是一頭栽進去，因為對手已經在做。能源交易有人說比較猶豫，還在建立對輸出的信任，但 Claude 這類模型的結果開始讓管理層採用。場子裡也不只工程師，有人是 vibe coding 把自己做進問題裡才來學。

## 三個人的說法

[0:00](https://www.youtube.com/watch?v=eBt8aw5bNyU&t=0s) 問的是 fintech、finance 今天的採用。回答是正往採用衝，每個人都想當競爭者、找出取得競爭知識的最好方式。你不做，對手大概在做。所以要早點納進來，能採用多少就多少。

[0:30](https://www.youtube.com/watch?v=eBt8aw5bNyU&t=30s) 另一個人說 AI 不會消失，越來越多人把它寫進 best practices。他注意到自己在聊的比較不是工程師。很多非工程師 vibe coding 把自己做進一個問題，然後來這裡學。

[0:48](https://www.youtube.com/watch?v=eBt8aw5bNyU&t=48s) 能源交易這行他覺得採用比較猶豫，尤其是相不相信輸出。情況在變，Claude model 的結果、跟新 framework 合在一起對生產力的影響，他說是 game changing，管理層開始採用。
