# Introducing Tessl Agent

片長 1 分 48 秒，英文手寫字幕。產品介紹。簡介說 Open Beta，試用頁是 tessl.io/agent。字幕沒有念網址。

- 原片：[YouTube](https://www.youtube.com/watch?v=1QaAPfsEqYQ)

## 一句話

讓 coding agent 變有效，本身是計畫外的工作。Tessl Agent 掃 PR、issues 和其他 coding agent 的 session logs，找出重複的錯誤和可以自動化的雜事，讓你繼續專心出貨。

## 他們看到的三種人

[0:02](https://www.youtube.com/watch?v=1QaAPfsEqYQ&t=2s) Tessl Agent 做的是自動、漸進、會複利的 codebase 改進。他們做它，是因為讓 agent 更有效這件事常常是 unplanned work。

[0:15](https://www.youtube.com/watch?v=1QaAPfsEqYQ&t=15s) 三種典型狀況。第一，你只顧出貨，agent 一直犯同樣的錯，花掉時間和 tokens。第二，你轉去把 agent 調有效，feature 速度會慢一段無法預期的時間，而且你在試的 harness 改動不知道有沒有用。第三，你自己做自動化工具，結果變成研究員，追論文、部落格、Twitter，幾週後全部過期。

[0:46](https://www.youtube.com/watch?v=1QaAPfsEqYQ&t=46s) 他們要的是另一個 agent，替你把其他 coding agents 變有效。它掃 PRs、issues，以及其他 coding agent 的 session logs，找重複錯誤和該自動化的雜事。結果是你比較少糾正它們、code review 時間變少，那些一直想自動化的雜事終於被做掉，而你還是專心在預算和時間內把東西交給使用者。

[1:09](https://www.youtube.com/watch?v=1QaAPfsEqYQ&t=69s) 他說這比較好玩、比較有效、比較可預期，是從現在走到真正 AI native 的工具。對象是已經在 production 用 agents、又在 feature 速度和變成 AI native 之間拉扯的人。
