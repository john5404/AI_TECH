# Tessl Release Roundup - March 12th, 2026

片長 2 分 1 秒，自動英文字幕。字幕把 Tessl 聽成 Tesla 或 Tessle。簡介說這段是 Dru Knox（head of Product）在講，字幕沒有念出名字。

- 原片：[YouTube](https://www.youtube.com/watch?v=pkWpzUDBaHY)

## 一句話

這一週四件事：skills 可以全域安裝、`watch local` 會把開發中的 skill 同步到所有 agents、eval 分數可以做成 GitHub badge、registry 上的兩種評分合成一個總分。

## 四項更新

[0:00](https://www.youtube.com/watch?v=pkWpzUDBaHY&t=0s) 不是每個 skill 都該裝進單一 repo。個人 workflow 或跨專案的偏好，現在可以全域安裝，所有專案共用，又不打亂隊友的流程。

[0:28](https://www.youtube.com/watch?v=pkWpzUDBaHY&t=28s) `watch local` 是新的命令列旗標。以前改一個已經裝進很多 agents 的 skill，得複製到每個 agent 的資料夾再重開 session。開了這個旗標，在 Tessl 裡改 skill，會自動同步到所有 agents。

[0:57](https://www.youtube.com/watch?v=pkWpzUDBaHY&t=57s) Eval 分數可以放上 GitHub badge，讓別人在安裝前看到這個 skill 的品質。

[1:16](https://www.youtube.com/watch?v=pkWpzUDBaHY&t=76s) Registry 的評分有兩種：reviews 對 best practices，task evals 讓 agents 跑模擬情境、看對真實結果的影響。現在有一個把兩者混成的單一總分，人和 agent 都能拿來看這個 skill 適不適合自己的 workflow。
