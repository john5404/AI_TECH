## 一句話

context 不只在文件裡。咖啡和電梯裡講的、還在腦子裡的，都是。要把 agent 放到背景跑，得先限制它的 context 和 access，不然無法信任。

## 對話裡的兩點

[0:00](https://www.youtube.com/watch?v=vLRIe8za00E&t=0s) 一個人說對他在做的東西，context 到處都在：文件裡有，跟同事喝咖啡、搭電梯時也在談，那些怎麼進到 AI？還有在腦子裡、得靠訪談才挖出來的小塊 context。另一個人說 context 的定義每天都在變。

[0:32](https://www.youtube.com/watch?v=vLRIe8za00E&t=32s) 問題變成：什麼條件下才敢把 agent 推到背景？基礎設施他們說有了，agent 可以在雲上跑、接到東西。可是要信任背景裡的 agent，唯一辦法是限制它的 context 和 access。

[0:50](https://www.youtube.com/watch?v=vLRIe8za00E&t=50s) 若 agent 很懂自己的任務，它也該知道自己還缺什麼。多數時候是人在告訴它要知道什麼、能碰什麼。如果它能反過來說：你給了這些文件，可是我還需要那一類，那才是他說的 ultimate context。
