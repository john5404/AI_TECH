# Tessl Academy: Learn AI Coding On Your Own Codebase

片長 56 秒，英文手寫字幕。產品預告。

- 原片：[YouTube](https://www.youtube.com/watch?v=Nm8N5BThi58)

## 一句話

一般 AI coding 教學在別人的機器上看完，回到自己的 repo 就散了。Tessl Academy 讓同一課可以當文章讀，也可以裝進你已經在用的 coding agent，在你自己的 repository 上走一遍。

## 它要你做出的事

[0:00](https://www.youtube.com/watch?v=Nm8N5BThi58&t=0s) 每套 AI coding 教學都有同一個問題：看別人做完，關分頁，到自己機器上，大部分學的東西過不了這趟。

[0:10](https://www.youtube.com/watch?v=Nm8N5BThi58&t=10s) Tessl Academy 是他們想修這件事的 hands-on curriculum，對象是你已經在用的 agent。每課有兩種走法：在網站上當文章讀，或把課程裝起來，讓自己的 coding agent 在你的 repository 上帶你走。只有後者會留下能跑的 code。

[0:29](https://www.youtube.com/watch?v=Nm8N5BThi58&t=29s) 你會寫出第一個 skill，看 agent 在沒有被提醒時自己去用它，給它一個好不好的數字，然後把團隊只放在腦子裡的 conventions 教給 reviewer。

[0:39](https://www.youtube.com/watch?v=Nm8N5BThi58&t=39s) Claude Code、Cursor、Codex 或 Tessl 都可以，帶你已經在用的那個。免費，起點是 tessl.io/academy。
