# GitHub Next & Tessl on the Self-Merging Repo

片長 10 分 36 秒，英文手寫字幕。剪輯。Don Syme 提出 CI、CD，再加上 continuous AI。後面有人報了三十天的出貨數字，以及一個用語音問 agent 的例子。中間有幾段沒被摘到。

- 原片：[YouTube](https://www.youtube.com/watch?v=9GArVPhHGkQ)

## 一句話

GitHub Next 的 Don Syme 說，我們一直缺一根柱子。不是 CI/CD，是 CI、CD，再加上 continuous AI。另一段給了三十天的數字：開了 295 個 issues，交出 217 個，81 個關掉。從分流到出貨的中位數是 1.6 小時。五個人一個月大約 3,000 美元，比以前快很多。

## 缺的那根柱子

[0:00](https://www.youtube.com/watch?v=9GArVPhHGkQ&t=0s) 六月倫敦，幾個講者從完全不同的方向走到同一個想法。

[0:07](https://www.youtube.com/watch?v=9GArVPhHGkQ&t=7s) GitHub Next 的 Don Syme。他說我們一直缺一根柱子。不是 CI/CD，是 CI、CD 和 continuous AI。一年前他們做了一個概念計畫，幾乎像一個語言計畫：拿 continuous integration 和 continuous deployment 的精神，說我們其實一直缺了什麼。若要引入這個詞，就得給它意思。拆開之後，例子到處都是。產業裡很多人在做 continuous AI，提供在開發流程裡自動使用 AI 的東西。

[1:33](https://www.youtube.com/watch?v=9GArVPhHGkQ&t=93s) 把一切堆進個人生產力的問題是，個人身上有互相衝突的目標：要有產能，也要有品質。中間有一段沒被摘到。

## 三十天，217 個交出去

[2:46](https://www.youtube.com/watch?v=9GArVPhHGkQ&t=166s) Pull request 會自動合併。五個人在 30 天裡交出 217 個 issues，一個月大約 3,000 美元。他說不是在開玩笑，因為他可以給你看上台前剛合併的那張 pull request。它有第一次審查，然後這次過了。

[4:14](https://www.youtube.com/watch?v=9GArVPhHGkQ&t=254s) 最重要的是，他們的 UAT repo 裡有一行：測試是 source of truth。過去 30 天開了 295 個 issues。他交出 217 個。81 個關掉，因為是重複，或根本不會做。分流的中位數不是工時，是一天裡經過的小時，4.6 小時。從分流一路到出貨，含所有關卡，是 1.6 小時。

[4:58](https://www.youtube.com/watch?v=9GArVPhHGkQ&t=298s) 公司裡每個人有一份 Claude Code Max，200 美元，然後一個月再花大約 1,500 到 2,000 美元。他們現在一個月 3,000 美元就能比以前快很多倍地出軟體。中間有一段沒被摘到。

## 不再搜檔案，改搜想法

[8:17](https://www.youtube.com/watch?v=9GArVPhHGkQ&t=497s) 換了一段。他可以傳語音，或自己打字，把資訊浮上來。他忘記 CI/CD 管線裡想實作的是什麼，只記得來自 Microsoft、大概有四個步驟。他就問 agent。它說你大概是指這個、這個、這個，而且是對的。因為它懂他的 context，還問：這是為了那場演講嗎？他說自己持續有這個陪練。他們不再搜檔案，而是搜想法和 context。他有一個會主動幫他搜的 agent，也有一個能解釋他自己找到的搜尋的 agent。

[9:28](https://www.youtube.com/watch?v=9GArVPhHGkQ&t=568s) 他有一個 cron job 跑在 OpenClaw 上，追蹤 X 上某些帳號的某些詞，例如 agentic engineering，或跟他在意的管線有關的詞。他也追一些較小的帳號。有一個人 maybe 有 12 萬追蹤者， maybe 不算小眾，但他會跟上發生的事。這幾乎是他的報紙。他不看報紙，但什麼都讀，圍繞 agents 和 AI 的那些。每天早上浮給他。

[10:19](https://www.youtube.com/watch?v=9GArVPhHGkQ&t=619s) 片尾約十一月紐約的 AI DevCon。
