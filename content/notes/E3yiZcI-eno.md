## 一句話

他問的是：AI 的世界裡還要不要用 framework。Code 變便宜了。他用 AI SDK 和 TypeScript 從零做了一個東西，後來發現有平台會幫你做 agent orchestration，兩三天、42 個 commits、大約四萬行就遷過去。要活下來就得幾天內交出去，而且要挑一塊你懂、你在乎的資訊工作，建在 framework 上，看有沒有人要買。

## 不要再自己造輪子，但問題變了

[0:09](https://www.youtube.com/watch?v=E3yiZcI-eno&t=9s) 主持人介紹這是當天最後一位。題目是 to framework or not to framework。這些年學到的是不要一直重造輪子、不要什麼都自己做，因為可以建在很多 open source、很多人已經做過的東西上，更快到達。AI 的世界裡這代表什麼。Ryan Carson 是連續創業、連續創辦並賣掉公司的人。

[1:04](https://www.youtube.com/watch?v=E3yiZcI-eno&t=64s) 他先請每天寫 code 的人舉手，很多人。然後做一個想像練習：閉眼，想像你看過最大的倉庫。後面走到最近的方塊，摘錄沒留住。

[5:38](https://www.youtube.com/watch?v=E3yiZcI-eno&t=338s) 他 25 年前拿電腦科學學位。先是 PHP 網頁開發者，他說這點自己不好意思。然後創辦公司，建了並賣掉三家。他最有熱情的是教人寫 code，做了十年。那句沒說完。

[6:10](https://www.youtube.com/watch?v=E3yiZcI-eno&t=370s) Andrej Karpathy 把 agents 說成鬼魂。他覺得比喻好。它們不是人，也不是電腦，是你大約 400 毫秒就能召喚、開始吐 token 的空靈存在。目前大約有 32 兆美元，句子被剪掉。他說這比那一切都大。演講標題是這個問題，因為現在全部跟速度有關。每天把手放在鍵盤上的人，後面那句沒留全。

## Code 便宜，挑一塊資訊工作

[8:55](https://www.youtube.com/watch?v=E3yiZcI-eno&t=535s) 他用 AI SDK 和 TypeScript 從零做，那樣也可以。然後發現有平台會幫你做 agent orchestration。遷移大概花了 3 天。他記得 42 個 commits，大約 40,000 行。兩三天就做完。他說現在是 Chris 說的那個時代：code 便宜，要緊的是想法。他希望大家離開時想的不只是什麼在運作。更重要的是退一步：你在打亂的是哪一塊資訊工作。

[10:20](https://www.youtube.com/watch?v=E3yiZcI-eno&t=620s) 你完全知道 code 在發生什麼，不是我們該停的地方。若想在這個瘋狂的新世界活下來並贏，得在幾天內交出去，不是幾週、幾個月。得快。更重要的是挑一塊你懂、你在乎的資訊工作，建在 framework 上，讓它上線，看有沒有人要買。

[10:54](https://www.youtube.com/watch?v=E3yiZcI-eno&t=654s) 他知道是一天的結尾，所以不講久。離開時想你要打亂哪塊資訊工作、需要哪些鬼魂、需要多少盒子、哪些管子把它們接起來，然後盡快接到世界上。他在 X 上是 Ryan Carson。也有一個免費的群組 Build Crew，網址是 buildcrew.team。他要大家帶著鬼魂和盒子離開，用 frameworks 走快，把想法放到世界上。
