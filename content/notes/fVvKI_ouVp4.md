# Hamza Oza: Building Design Quality Into Software Factories

片長 77 秒，英文手寫字幕。AI DevCon 預告，不是那場演講的全文。

- 原片：[YouTube](https://www.youtube.com/watch?v=fVvKI_ouVp4)
- 講者：Hamza，Tessl 的 design lead。他說自己當 product designer 之前是機械工程師，在真正的工廠待過。

## 一句話

工廠學過：品質不能在產線末端才檢驗，得做進產線裡。software factory 一樣。他會講 Kikimora 裡現在抓設計缺陷的四個位置。

## 預告裡的四段，還沒展開

[0:00](https://www.youtube.com/watch?v=fVvKI_ouVp4&t=0s) 他問：agent 做了你要的東西，看起來卻完全不對，有沒有遇過。十一月紐約 AI DevCon，題目是把 design quality 自動化進 software factories。

[0:13](https://www.youtube.com/watch?v=fVvKI_ouVp4&t=13s) 真實工廠的教訓是不能在 production line 末端才 inspect quality，要建進產線。軟體工廠是同一個問題。

[0:29](https://www.youtube.com/watch?v=fVvKI_ouVp4&t=29s) 演講會走 Tessl 的 software factory Kikimora 裡、他們現在抓 design defects 的四個地方：agent 動手前就讀的 style rules、CI 裡的檢查、以及會掃整個產品找 drift 的 agents。他會講每一個抓到什麼、那代表什麼。聽完應能知道怎麼讓 agent 真的跟著設計指引走，以及當它們負責製作之後，你的工作可能怎麼變。

[0:56](https://www.youtube.com/watch?v=fVvKI_ouVp4&t=56s) 對象是 designer、product manager、front-end engineer，尤其是 agent 出 UI 的速度快過任何人審得完的人。折扣碼 HAMZA30，30%。
