# Introducing Tessl: The Package Manager for Coding Agent Skills

片長 99 秒，英文手寫字幕。產品介紹。

- 原片：[YouTube](https://www.youtube.com/watch?v=RbJ_GIPKxUI)

## 一句話

Skills 不是複製一段文字。Tessl 把自己做成 skills 和 context 的 package manager：消費的人用 `tessl.json` 安裝、更新、看 eval；生產的人可以評估、最佳化、發版，並在相關軟體變了之後把 skill 更新，避免它過期然後誤導 agent。

## 消費和生產

[0:00](https://www.youtube.com/watch?v=RbJ_GIPKxUI&t=0s) Skills 用來引導 agent，比改 `agents.md` 或加文件更進一步。要管的不只是把字搬來搬去：長期誰擁有、有沒有效、一開始選哪一個。

[0:16](https://www.youtube.com/watch?v=RbJ_GIPKxUI&t=16s) 消費端：可以安裝任何 skill，`tessl.json` 記下裝了哪些，並幫忙更新。每個消費的 skill 都有 evaluation，用來判斷哪個對、哪個不對。它會裝到你有的所有 agents，而不在 repository 裡複製內容。

[0:33](https://www.youtube.com/watch?v=RbJ_GIPKxUI&t=33s) 生產端：幫你 evaluate 和 optimize，再 publish、version，讓使用者知道自己在用什麼、並停在最新版。它會追相關軟體的變更，需要時更新 skill，避免 skill 變舊、誤導 agent。

[1:02](https://www.youtube.com/watch?v=RbJ_GIPKxUI&t=62s) 他的收法是：skills 和 context 不只是文字，它們是 agentic development 裡的 software unit。Tessl 是給開發者用的 package manager，也是組織裡管理 context 的平台，讓 agent 在對的時間拿到對的 context。免費起點是 tessl.io/registry。組織試用要另外聯絡。
