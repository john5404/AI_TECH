# Installing the Tessl CLI

片長 36 秒，自動英文字幕。短教學。字幕把套件名和指令聽歪了；命令以下面影片簡介寫的為準，因為那裡寫的是 `npm install -g @tessl/cli` 和 `tessl --help`。Tessl 在字幕裡常被聽成 Tessle。

- 原片：[YouTube](https://www.youtube.com/watch?v=M8aQ1xCbijs)

## 一句話

用 npm 全域安裝 Tessl CLI。先決條件是 Node.js 22 或更高。裝完用 `tessl --help` 確認，再去某個專案裡 init。

## 步驟

[0:01](https://www.youtube.com/watch?v=M8aQ1xCbijs&t=1s) 這支片示範把 Tessl 裝到機器上。CLI 用 npm 下載，需要 Node 22 以上。

[0:14](https://www.youtube.com/watch?v=M8aQ1xCbijs&t=14s) 在 terminal 執行全域安裝。簡介給的指令是 `npm install -g @tessl/cli`。

[0:20](https://www.youtube.com/watch?v=M8aQ1xCbijs&t=20s) 用 help 檢查 CLI 是否能跑。簡介寫的是 `tessl --help`。

[0:28](https://www.youtube.com/watch?v=M8aQ1xCbijs&t=28s) 安裝成功之後，下一步是在一個專案裡初始化 Tessl。
