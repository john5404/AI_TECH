## Llama 是開放創新，不是 open source

[0:00](https://www.youtube.com/watch?v=YN3dbi4hWUM&t=0s) 全球只有兩個主導者，中國和美國，其他人差很遠。中間大約十國。沒有協作式創新，就負擔不起那兩邊建的東西。2023 年第一批 LLM 開放時，先是 Llama 外洩，然後七月正式開放，創新速度前所未見。開放的價值是迭代：本來碰不到的技術可以自由拿來用、往上蓋。他看到的轉移是從 Meta 的 Llama 到 DeepSeek 的 R1。

[0:50](https://www.youtube.com/watch?v=YN3dbi4hWUM&t=50s) Meta 說 Llama 是 open source，Linux Foundation 背書，他們公開反對。2023 年七月，Open UK 是唯一把 Llama 的發布支持成 open innovation 的組織。他記得是 7 月 23 日。授權有兩件事：acceptable use policy 加了限制；還有商業條款，使用者到了某個百萬級就要回去跟 Meta 拿商業授權。沒有人知道那份授權的條件，因為他覺得還沒有人達到可追蹤的那個用量。Open source 的基本原則是任何人、任何目的都能用。這裡始終有限制的風險，輸出也不能自由地傳下去讓別人迭代。所以那條斷了。當成 open innovation 可以，他們支持，而且他仍覺得對：把一個 LLM 開放，是產業改變的關鍵，會被記成轉捩點。

[2:10](https://www.youtube.com/watch?v=YN3dbi4hWUM&t=130s) 現在街上的說法是 Meta 在離開開放。他覺得是因為沒做對，沒有做出真正的 open source。他們自己一開始也不叫 open source，直到 Zuck 在 Facebook 上貼了。那之後沒有人走得回去。是不是故意的，除非他自己說，不會知道。

## 蒸餾，以及中國開發者實際在用什麼

[2:31](https://www.youtube.com/watch?v=YN3dbi4hWUM&t=151s) DeepSeek 是蒸餾模型。他先說 R1 open，再改口是 R1，不是 R1 open。蒸餾是拿 Qwen 和 Llama 裡的東西，做出等價的東西，而不從零訓練。衝擊是把建模型的價格從大約一億降到五百萬，當時成本的 5%。他覺得那次蒸餾對那個時間點的創新很大。

[3:09](https://www.youtube.com/watch?v=YN3dbi4hWUM&t=189s) 十二月他去中國。幾年前他編過一本 open source law 的書，中文開放源碼社群譯成普通話，640 頁，花了不少時間。他在那裡跟 DeepSeek 通過電話，內容他不能具體講。跟市場上的人談也很有趣。DeepSeek 很大，Qwen 和 Kimi 也是，但中國每個開發者似乎都在用 Kimi，而且在開發者這邊跑在前面。

[3:57](https://www.youtube.com/watch?v=YN3dbi4hWUM&t=237s) 主持人說 Reddit 或 Hacker News 有傳言，Kimi 是 Cursor 剛出的 Composer 2 背後的核心模型。他不知道是不是在釣人、有多少是真的。越來越清楚的是，不是每個模型都從零建，模型在互相學。對方說必須是這樣。

## 什麼時候該用便宜的開放模型

[4:30](https://www.youtube.com/watch?v=YN3dbi4hWUM&t=270s) 問的是開發者何時該用貴的，例如 Opus 或 OpenAI 的模型，何時用這些彼此衍生、對終端使用者自然更便宜的模型。他說現在很怪：開放這一側的採用，比你預期的低很多，很像二十年前的 open-source software。原因類似：風險管理、不理解、也許不必要的恐懼、不知道開放的後果。當時是風險專業、律師、採購、財務在合約上說不。後來動能繞著 GitHub 起來。他預期不會是某個工程師單獨做決定，而是整個產業變成常態。他覺得不可避免。過去幾週他在活動上聽到 Yann LeCun 說同樣的話，覺得安心。尤其不是來自美國或中國的人，沒有別的路。來自中國的人，大概已經在用開放模型。
