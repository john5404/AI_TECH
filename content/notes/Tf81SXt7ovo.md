## 一句話

他手機上的模型比一年前的 ChatGPT 好。筆電上的比去年十一月的 Claude Sonnet 和 Opus 好。前沿模型現在又超前大約六個月，但一般寫 code、不必面對客戶的工作，他用大約二十分之一成本的模型，整夜在公司的機器上跑。除了寫 code，他建議幾乎一切都在本地跑。本地模型不是自動就私密，但可以斷網，讓錄音只屬於你。

## 本地已經追上六個月前的前沿

[1:06](https://www.youtube.com/watch?v=Tf81SXt7ovo&t=66s) 主持人以為本地模型不行。他說完全不是。今天手機上的模型比一年前的 ChatGPT 好。筆電上的比 ChatGPT，也比去年十一月的 Claude Sonnet 和 Opus 好。那是六個月前。前沿模型現在又好了六個月。

[1:38](https://www.youtube.com/watch?v=Tf81SXt7ovo&t=98s) 若你在寫 code，而且是一般的 code，不必跑在自己的筆電上。他點的名字包括 GLM 5.1，以及字幕聽成 Kimiko 2.6、mini LM M2.7 的兩個，還有 DeepSeek V4。這四個若在跑，成本大約是二十分之一。不必出去給客戶的一般 coding，他讓自己的機器整夜跑。公司裡多台筆電和機器，大部分時間跑的是那個被聽成 Kimiko 2.6 的模型。

[3:10](https://www.youtube.com/watch?v=Tf81SXt7ovo&t=190s) 價格是大因素，尤其前沿模型幾乎每天更貴。主持人說自己被補貼過的 token 經濟寵壞了，習慣一個月十美元跑前沿模型。這句之後摘錄跳了一段。

[4:30](https://www.youtube.com/watch?v=Tf81SXt7ovo&t=270s) 語音轉文字這類，包括這支片自己會被轉寫的那些模型，本地跑可以百分之百一樣好，很多時候更好、更快。模型讀得比寫得好很多。他打比方：你說英語時，他立刻知道你聽得懂，流利百分之百。中間又有一段沒被摘到。

[5:53](https://www.youtube.com/watch?v=Tf81SXt7ovo&t=353s) 他覺得這些模型很適合從雲端前沿訂閱換過來。它們 24 小時跑，會燒很多 token，而對它們在做的事已經夠好。手機上的今天就做得到。進會議時，它們在撿資訊、在處理。也就是個人助理：看信、看行事曆、挑重要資訊、幫你準備會議。

## 什麼時候不要用前沿訂閱

[6:50](https://www.youtube.com/watch?v=Tf81SXt7ovo&t=410s) 隱私。本地模型不是定義上就完全私密，但你可以讓它私密。它在手機或筆電上，可以斷網。錄下來的對話就完全是你的。他們在歐洲，隱私重要。用那些美國的東西，一切會被拿去訓練，然後不知不覺公開到網路上。

[7:22](https://www.youtube.com/watch?v=Tf81SXt7ovo&t=442s) 經驗法則：除了寫 code，都該看前沿訂閱以外的東西。寫 code 除非你有最新型、128 GB 的 Mac。他們跑的一切都是本地。主持人說這對他幾乎是革命性的，他會拿來試比現在更多的事。

[8:05](https://www.youtube.com/watch?v=Tf81SXt7ovo&t=485s) 你會得到更低的延遲。一個小的 Qwen 3.5 4B，推論會比 ChatGPT 快。字幕把 Qwen 聽成 Quen。片尾說接下來還有 Yianni 的訪談。
