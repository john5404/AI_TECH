# From Pilot to Platform: Scaling Coding Agents Across Teams

片長 41 秒，英文手寫字幕。這是一場 webinar 的邀請，不是研討會演講全文。字幕沒有念出講者名字；頻道簡介寫的是 Guy Podjarny 和 Patrick Debois。

- 原片：[YouTube](https://www.youtube.com/watch?v=ySZN5lpJgxI)

## 一句話

一個人在筆電上用 coding agent 很容易。要變成團隊、大型 codebase 上可重複的流程，就會卡在 context。

## 這場 webinar 要談什麼

[0:00](https://www.youtube.com/watch?v=ySZN5lpJgxI&t=0s) agentic development 很強，但把一個人在 laptop 上做得到的事，放大成團隊和大 codebase 上的可重複流程，會變得很棘手。

[0:10](https://www.youtube.com/watch?v=ySZN5lpJgxI&t=10s) webinar 要講 scale 時常見的失敗，以及可以做什麼。他先劇透：很大一部分是 context。

[0:19](https://www.youtube.com/watch?v=ySZN5lpJgxI&t=19s) 會提到 context 的常見用途，例如推出 policies 和 best practices、把平台寫成文件。也會談 context development lifecycle 怎麼接上 software development lifecycle，以及它怎麼 scale。
