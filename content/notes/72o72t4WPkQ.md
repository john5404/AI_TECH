# Using Tessl init for existing projects

片長 31 秒，自動英文字幕。短教學。字幕把 Tessl 聽成 Tessle；下文用 Tessl。

## 一句話

既有專案一樣跑 `tessl init`。差別只在於你從那個專案的根目錄開始，而不是先建新資料夾。

## 步驟
