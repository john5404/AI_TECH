# The Hallway Track: What Even Is Harness Engineering

片長 2 分 9 秒，英文手寫字幕。Simon Maple 在舊金山 AI Engineer 的走廊訪問。開頭有一隻小狗 Sunny，不能跟著走。

- 原片：[YouTube](https://www.youtube.com/watch?v=DLjarZe0Xqc)

## 一句話

這一週的詞從 harness engineering 走到 loop engineering。Loop 的好處是 agent 不會每做五到十步就回來問你。有人把這做成一個打寶可夢的 harness，微調在 open-weight model 上，而且很貴。會中途 Sonnet 5 發布了。

## 走廊裡聽到的

[0:03](https://www.youtube.com/watch?v=DLjarZe0Xqc&t=3s) Simon 先跟小狗 Sunny 打招呼，然後說小狗得留在原地，他自己去問人這場在談什麼、想學什麼。

[0:31](https://www.youtube.com/watch?v=DLjarZe0Xqc&t=31s) 有人說這週從 harness engineering 開始，現在夢想詞彙是 loop engineering。對方確認還是這樣，並說過去 30 分鐘 Sonnet 5 發布了。

[0:45](https://www.youtube.com/watch?v=DLjarZe0Xqc&t=45s) Loop 的主要好處：agent 不會每五到十次操作就回來要你的輸入。模型對長時間任務的想法已經根本改變。不久之前，就算你鼓勵它繼續、甚至用 channels 這類新功能把通知推進 session，它還是會繞回來說不知道你要什麼，或丟三個選項請你選。

[1:21](https://www.youtube.com/watch?v=DLjarZe0Xqc&t=81s) 另一個人補：要有真正的 feedback loop，agent 得懂正在做的事，而且 memory 要能更新。今天有價值的，兩天後可能沒價值。問題是它要怎麼調那些權重。

[1:36](https://www.youtube.com/watch?v=DLjarZe0Xqc&t=96s) 有人說倫敦講過一個片段：self-healing 的寶可夢 agent，讓 code 邊玩邊被訓練。這次進階成訓練一個模型。他做了一個打寶可夢的 harness，微調在 open-weight model 上。他說不要在家試，非常貴。演講在樓上，一小時。
