# Introducing Tessl Spec Registry

片長 1 分 58 秒，自動英文字幕。產品介紹。字幕把 Tessl 聽成 Tesla。

## 一句話

Agent 缺的是訓練截止之後的函式庫、團隊怎麼用某個 framework、以及公司政策。Spec Registry 把這些 spec 像依賴一樣加進專案，任何 agent 都能用。裡面已經有超過 10,000 份熱門 open-source library 的 usage specs，而且版本對得上函式庫版本。Beta，免費。

## 它在補的洞

[0:00](https://www.youtube.com/watch?v=PAy2c4r_UEM&t=0s) Agent 再聰明也有不知道的事：訓練之後才出的 open-source library 新版本、團隊決定怎麼用某個 framework、必須遵守的公司政策。

[0:15](https://www.youtube.com/watch?v=PAy2c4r_UEM&t=15s) 不能指望 agent 自己決定去查、而不是幻覺一個答案，而且它的 memory 有限。Agent 每週都有新的，團隊在用的每一種都很難逐一支援。

[0:30](https://www.youtube.com/watch?v=PAy2c4r_UEM&t=30s) Spec Registry 把這些資訊做成專案的一部分。Spec packages 像軟體依賴一樣加進去，任何開發這個 app 的 agent 都能用，而且設計成 agent 容易吃、容易照做。內容是 code 裡沒有、agent 卻需要的 context：open-source library 的說明和例子、常見工作的可重複 workflow（例如加 analytics、修安全問題），以及你自己的 practices 和 policies。

[1:23](https://www.youtube.com/watch?v=PAy2c4r_UEM&t=83s) 已經有超過 10,000 份熱門函式庫的 usage specs。它們根據深入分析和真實使用資料，寫清 agent 該怎麼用這個函式庫，用來加快開發、減少犯錯。Usage specs 的版本對應函式庫版本，所以很新或很舊的函式庫也還能用。Beta，免費。
