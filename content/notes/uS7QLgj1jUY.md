# We Scored a Real Snyk Skill Against Anthropic's Rules

片長 15 分 19 秒，英文手寫字幕。Simon Maple 在舊金山 AI Engineer 的展場，現場評一個 Snyk 的 skill。來賓叫 Chris。有一個分數字幕聽成 8077，不採用。清楚說出來的是 87% 到 90%。

- 原片：[YouTube](https://www.youtube.com/watch?v=uS7QLgj1jUY)

## 一句話

現在多半是每個人自己寫 skills：跟 coding agent 做一場，結束時想留下可重複的東西。現場這個 Snyk skill 從 87% 到 90%，加了 3 個百分點，碰到他們設的 90 分門檻。大改是把 `SKILL.md` 裡的程式碼塊拆出去，讓 agent 需要時才 progressive disclosure。還有 10% 沒走完。個人 skill 也許可以將就。要分享給團隊，就該放進 pull request 的檢查，避免退步。

## 展場上抓到的 skill

[0:02](https://www.youtube.com/watch?v=uS7QLgj1jUY&t=2s) 開場就說它移動了 3%，從 87% 到 90%。Simon 說現在是大家各自寫自己的 skills。你 prompt coding agent、做一場 session，結束時想要一個可重複的東西。

[0:24](https://www.youtube.com/watch?v=uS7QLgj1jUY&t=24s) 他在舊金山 AI Engineer 的展場走，看到一道光，是 Chris 走過來，說 Simon，我需要你評我的一個 skill。Chris 在 Snyk。後面一段玩笑沒被摘全。Simon 說跑之前要有禮貌。

[4:25](https://www.youtube.com/watch?v=uS7QLgj1jUY&t=265s) 他們開始跑。Simon 說若這裡是 0%，maybe 只是沒對上 Anthropic 的 best practice。他希望不是 100，因為那就沒東西可改。若是 100，Chris 可以拿走 Tessl 的贈品。有一個分數字幕聽成 8077，不採用。

## 不要一次載完整份

[6:38](https://www.youtube.com/watch?v=uS7QLgj1jUY&t=398s) 要能判斷什麼時候用哪一個。Skill 平常不會被完整載入。它大概會建議把很多內容拆成子檔，再引用那些不同的部分。

[9:11](https://www.youtube.com/watch?v=uS7QLgj1jUY&t=551s) 問題是它腫了。Simon 猜它會把這份縮小，你會看到額外的檔。

[10:26](https://www.youtube.com/watch?v=uS7QLgj1jUY&t=626s) 例如有一個 skill 知道怎麼推到 production。他們希望平台團隊發布那個 skill 給開發者用，因為這樣才能過安全和品質的要求。他們大致在做兩件事。句子沒說完。

## 87 到 90，還有一成

[11:25](https://www.youtube.com/watch?v=uS7QLgj1jUY&t=685s) Simon 說他可以告訴你什麼會把它弄到 100%。你自己寫的 skills 要這樣，第三方 skills 也非常重要，因為第三方 maybe 是惡意的。第一方和第三方的問題會是不同類別。

[12:44](https://www.youtube.com/watch?v=uS7QLgj1jUY&t=764s) 它只加了 3%。Simon 說自己還是會戴著這個。然後是從 87 到 90。它碰到目標分數 90。程式碼塊從 `SKILL.md` 移到新的 references。它把擴展拆成更小的片段。現在一個大變化是，agent 需要那些特定片段時才 progressive disclosure。還有一整批變更看得到，包括額外的紀錄和格式。`SKILL.md` 在這個階段會比較短。裡面某個點會連出去，但沒有 Simon 預期的那麼滿，他以為每種驗證方法的完整程式碼都會在。再跑幾次 maybe 會再做。他們還有 10% 要走。可以再看它還想改什麼、會不會繼續迭代。他說還不壞。

[14:19](https://www.youtube.com/watch?v=uS7QLgj1jUY&t=859s) Chris 說尤其是他要分享 skills。他自己不知道它們好不好。個人 skills maybe 沒關係。他想分享給團隊。可以放進 pull request 的檢查。一有 pull request、動到 `SKILL.md`，就再跑審查，確認沒有退步。

[14:42](https://www.youtube.com/watch?v=uS7QLgj1jUY&t=882s) 可以免費試。立刻能開帳號。免費帳號有一些點數，一個月內用，每個月補一次。Simon 說那 3% 可以免費拿到。Chris 也謝謝那頂帽子。
