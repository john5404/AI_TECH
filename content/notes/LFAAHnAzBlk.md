# Your AI Isn't Stupid, It's Blind: Ran Aroussi on Memory

片長 50 秒，英文手寫字幕。AI DevCon 預告。

- 原片：[YouTube](https://www.youtube.com/watch?v=LFAAHnAzBlk)
- 講者：Ran Aroussi。他說自己寫了 yfinance，現在跑 VarOps。

## 一句話

agent 不是笨，是看不見。多數 memory 只是一堆 raw text 加上搜尋框。他要做的不是多存，而是蒸餾知識、追變更，並在來源消失後還守住 permissions。

## 預告裡的主張

[0:00](https://www.youtube.com/watch?v=LFAAHnAzBlk&t=0s) 開場就是這句：Your AI isn't stupid, it's blind。重要決定常常落在 memory 看不到的地方。

[0:11](https://www.youtube.com/watch?v=LFAAHnAzBlk&t=11s) 過去一年他在做 company-scale agents 的 memory。修法不是 storing more，而是 distilling knowledge、tracking changes，並且在 source 消失之後 permissions 還在。

[0:24](https://www.youtube.com/watch?v=LFAAHnAzBlk&t=24s) 他說這件事做對，一個不起眼的 local model 可以達到 frontier quality 的 99%。紐約 AI DevCon 他會講他們怎麼做。報名是 aidevcon.io。
