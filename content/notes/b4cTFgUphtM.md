一两年後的預測基本上會錯。我們會繼續做軟體，同時維護已經在外面的幾十億、甚至幾兆行 code。一年前沒人料到開發者會回到終端機，同時開六到八個，裡面跑 Claude Code、Gemini CLI、Codex CLI 和 Copilot CLI。競爭會逼在位者變好。企業銷售仍是關係，AI 取代不了。

## 競爭把在位者推向多模型

[3:32](https://www.youtube.com/watch?v=b4cTFgUphtM&t=212s) 他用一級方程式：Red Bull 贏了四年，Mercedes 大約八年，然後 Red Bull 又四年。你會想要這些更迭，它會激勵曾經贏過的人。他 2007 或 2008 年開始用 Mac，當時 TextMate 是革命，後來變陳舊，TextMate 2 拖太久。在位者跟不上。競爭是最大的動力。

[5:04](https://www.youtube.com/watch?v=b4cTFgUphtM&t=304s) 在 GitHub，這迫使他們在 2024 年從 Copilot 只有一個預設模型，改成多模型。2024 年 10 月或 11 月的 GitHub Universe，他宣布當時支援 Claude（他記得大概是 Claude 3）和 Gemini 1.5 Pro。句子在這裡被剪掉。競爭讓在位者的產品也變好。

[5:49](https://www.youtube.com/watch?v=b4cTFgUphtM&t=349s) 看 Microsoft，它大概是外面最大的平台公司。不只 Copilot 和 GitHub 提供某種中立和選擇。Azure Foundry 有很大範圍的模型，不只 OpenAI 和 Microsoft 自己的，還有 Mistral、Black Forest Labs、很多 open source，你也可以部署自己的模型。所以瑞士那種中立比喻不如直接說它是平台公司。平台公司本來就想讓盡量多的玩家站在平台上，例如 GPU 推論、CPU、儲存。這同時幫 Microsoft 和夥伴。Microsoft 作為生意的槓桿是那個平台的規模。

[6:51](https://www.youtube.com/watch?v=b4cTFgUphtM&t=411s) 每個新創都有機會進 Microsoft startup program。對方說他們差不多每個計畫都在。每個新創，尤其 B2B，會到一個點，想用 Microsoft、Amazon 或 Google 的通路和企業銷售團隊。那些團隊的規模和本事，遠超過小新創不經歷痛苦就能自己做出的：子公司、本地辦公室、本地 meetup。那是大量的人力投資。AI 取代不了，因為企業銷售根本上仍是關係管理。
