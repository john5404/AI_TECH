## 一句話

Memory engineering 不是新職業的憑空發明，而是資料庫、搜尋最佳化、軟體和一點 AI 工程的交叉，專注把 agent 系統裡的檢索管線調好。Skills 則是給 agent 的 SOP，也就是程序性記憶。名字這個月叫 skills，下個月可能就換了。

## Memory 和 context

[0:00](https://www.youtube.com/watch?v=iVa0NP3u74s&t=0s) 問有沒有 context engineer 或 memory engineer 的位置。他說有，但頭銜還沒定。Memory engineering 是幾門的交叉：database engineers、search optimization、software engineers，再加上一點 AI engineering。交叉之後，這群人專注最佳化 agentic system 裡的 retrieval pipelines。

[0:32](https://www.youtube.com/watch?v=iVa0NP3u74s&t=32s) Memory management 是不是 context management 的超集，他覺得是個有趣的辯論。他把一切看成 memory，因為這個詞能接上非技術的人。跟媽媽或祖母說 memory，她們懂。說 context，她們沒有那個 context。手機裡的 agent 需要記住你給它的資訊，那就是 memory。於是你會開始想怎麼提高某則資訊被召回的機會，也就是最佳化檢索管線。他承認也可以主張一切都是 context。

## Skills 是給 agent 的 SOP

[1:45](https://www.youtube.com/watch?v=iVa0NP3u74s&t=105s) Simon 問 skills 跟 context 的關係，也提到 Tessl 在網站上要先寫 skills 還是 context，兩者有重疊。受訪者說這個階段命名很重要，但比命名更難的是它變得太快，這個月叫 skills，下個月叫別的。去年初還沒有人說 skills。

[2:21](https://www.youtube.com/watch?v=iVa0NP3u74s&t=141s) 他用人類類比。Skills 不是新東西，人類的對應物是 SOP，standard operating procedures：組織裡定義某件任務怎麼做的文件，用來把做法交給下一個被雇來的人。結構是步驟，對到一個結果。Skills 就是給 agent 的 SOP：給任務一個任意名字、用一定長度描述它、給逐步指令，也許再給工具、腳本或 MCP 的位置。

[3:20](https://www.youtube.com/watch?v=iVa0NP3u74s&t=200s) 放進 agent memory，skills 是程序性記憶。人腦裡存技能的是小腦，例如會不會後空翻。他問 Simon 會不會，Simon 說這個年紀不行，帶狗拴繩都會閃到腰。從 agent memory 看，skills 就是 agent 的程序性知識。
